# ProcureAI

Intelligent Procurement. Better Decisions.

Hackathon MVP frontend — React + Vite + Tailwind, mock data only, no backend.

## Flow
Dashboard → Create RFQ → Quote Comparison → AI Analysis → Select Vendor → Purchase Order

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```
